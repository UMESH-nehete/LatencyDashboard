# Network Latency Dashboard

Interactive Streamlit dashboard for analysing latency logs from TCP, UDP and WebRTC experiments.

## Installation

```bash
git clone <repo>

cd LatencyDashboard

python3 -m venv venv

source venv/bin/activate

pip install -r requirements.txt
```

Run

```bash
streamlit run app.py
```
